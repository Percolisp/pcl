# docs/history/

Superseded planning and status documents, kept as project history (moved
here from the repo root in s419, task #279).  Nothing in this directory is
current: the live entry points are the top-level `CLAUDE.md` ("Key Files to
Read"), `docs/DECIDED.md`, and `docs/session-log.md`.  Files here may
contradict the present code — they record what was planned or true at the
time they were written, and they are not updated.
