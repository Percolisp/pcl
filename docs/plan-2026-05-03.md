**Fix 1 — `\(list)` reference to list (undef.t line 203)**

`\($y = undef)` → Cast(`\`) + Structure::List → should generate
`(p-ref-list (p-scalar-= $y (p-undef)))` or similar.

In Perl, `\(e1, e2)` = list of refs to each element.  PCL needs to handle
`Cast('\')` + `Structure::List` as a new node type `ref_list`.

In ExprToCL.pm, `gen_prefix_op` handles `\` + scalar → `(make-p-box ...)`.
For `\` + list, generate `(p-array-init (make-p-box e1) (make-p-box e2) ...)`.

**Fix 2 — `->$*` postfix scalar dereference (undef.t line 206) ← DONE (session 162)**

`$x[0]->$*` = postfix deref of scalar ref.  PPI gives:
- `$x[0]` Symbol + Subscript
- `->` Operator  
- `$*` Cast (content `$*`)

The method-call path in `handle_method_calls()` in PExpr.pm encounters `$*`
(a Cast token with content `$*`) as the "method name" and doesn't know what
to do with it.  Need to recognise `->$*`, `->@*`, `->%*`, `->@[...]`, `->@{...}` as
postfix dereference forms and generate `(p-deref-scalar ...)` etc.
