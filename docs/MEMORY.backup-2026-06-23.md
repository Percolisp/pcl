## Helper Scripts
- `./runt <name>` — transpile `perl-tests/<name>.t` → `/tmp/<name>.lisp`, run SBCL, print filtered output. See `memory/reference_runt_script.md`.
- `./clt <name>` — transpile `perl-tests/<name>.t` → `/tmp/<name>.lisp`, print lisp to stdout (no SBCL). For quickly inspecting generated CL.

## Key Method Dispatch Gotchas
- **Method names are strings**: `p-method-call obj "method-name" args` — NOT `'symbol`. CL reader case-folds uniform-case `'foo`→`FOO` (true even under `:invert`, which only preserves *mixed* case), breaking lowercase method names and AUTOLOAD dispatch. Always emit as string literals. Dispatch resolves the string to the sub's CL symbol via `%pcl-cl-sub-name` (which applies the same `:invert` transform), so strings do NOT bypass case-handling — they're what makes it consistent.
- **AUTOLOAD**: `p-method-call` now calls `%pcl-dispatch-autoload` after failing to find the method. Walks @ISA for PL-AUTOLOAD, sets `$PKG::AUTOLOAD`, dispatches. Skips DESTROY.
- **UNIVERSAL implicit parent**: All Perl classes implicitly inherit UNIVERSAL. `p-method-call` tries `find-in-class "UNIVERSAL"` after exhausting the object's own chain, in both CLOS-MRO and @ISA-walk paths.
- **p-defpackage initializes @ISA**: Every package now gets `@ISA` bound to empty adjustable vector on first declaration. This is needed for `isa-non-empty` detection in `p-method-call`.
- **Qualified dispatch `$obj->PKG::method`**: Handled in `p-method-call` — when method-name contains `::`, dispatches directly to `PKG::pl-METHOD`. UNIVERSAL built-ins handled as special cases.
- **`PKG::SUPER::method`**: When meth-part starts with `SUPER::`, calls `p-super-call(obj, real-method, PKG)` to use PKG (not obj's class) as the "current class" for SUPER lookup.
- **Dynamic SUPER `$obj->$var` where `$var="SUPER::foo"`**: Detected in `p-method-call` early-exit before main dispatch.
- **`use base` / `use parent`**: Now handled by `_process_use_base` in Parser.pm — emits `@ISA` push + CLOS class redefinition. Previously silently ignored as a pragma comment.
- **Empty-string class → "main"**: `p-method-call` normalizes `""` to `"main"`, `"::"` to `"main::"`, and strips leading `"::"` from `"::Foo"` (Perl root-stash semantics).
- **`%pcl-find-package`**: helper that tries `(find-package (string-upcase pkg))` then `(find-package pkg)` — needed for `|main::|` and similar pipe-notation packages. Used in all p-method-call package lookups.
- **Tied scalar invocant**: `p-method-call` calls FETCH on tie-proxy boxes before class lookup — allows `$tied_var->method` where FETCH returns a class name.

## Key CL/Runtime Gotchas
- **NaN**: SBCL signals `FLOATING-POINT-INVALID-OPERATION` on `=`,`/=`,`<`,`>`,`<=`,`>=`,`zerop`,`minusp`,`sqrt`,`log`,`sin`,`cos` with NaN. Always guard with `(%pcl-nan-p n)` before any numeric predicate. `%pcl-nan-p` is in the `pcl` package, not exported. `pl-cmp_ok` in pcl-test.lisp also needs guarding.
- **Inf in integer ops**: `truncate`, `logior`, `logand` etc. crash on Inf. Use `%pcl-to-integer` (clamps Inf→0) for bitwise ops. `p-int` now clamps +Inf→2^63-1, -Inf→-2^63, NaN→0.
- **Float literal overflow**: `1e9999` etc. cause SBCL READ-ERROR. ExprToCL.pm now detects overflow at transpile time and emits `sb-ext:double-float-positive-infinity`.
- **Case collision `$T` vs `$t`**: now handled for FREE by `(readtable-case :invert)` (see [case-sensitivity SHIPPED](project_case_sensitivity_general_fix.md)). The older `_with_declarations` `$name__case__N` rename was RETIRED (969fb86) — no longer in the code.
- `defvar` must come BEFORE `defun` for `let` to create dynamic bindings
- `p-*` = runtime built-ins, `pl-*` = user-defined subs (no collision with Tie::Array etc.)
- `*p-undef*` is INTERNAL (not exported from `:pcl`) — use `(p-undef)` in generated code for user packages
- Loop macros use `tagbody`/`go` — `(block nil ...)` inside for unlabeled `p-last`; `(catch 'pcl::LAST-LABEL)` inside for labeled `p-last`
- `*read-default-float-format*` must be `'double-float`
- `p-return-value`: blessed boxes returned as-is; hash/array/fn boxes → inner value; plain scalar boxes → unboxed. **Context-sensitive (session 169):** in scalar context, plain adjustable vector → last element (list-in-scalar rule); in list context, nil → empty vector (empty list).
- `box-set` source value: if P-TIE-PROXY inside, FETCH is called (not copied)
- **GC moves objects — never cache address-based NV**: `box-nv` skips the NV cache for all reference-type box values (p-box, vector, hash-table, function, typeglob). `sb-kernel:get-lisp-obj-address` returns the live address; if we cached it, a post-GC call would get a different address for the same object, breaking `$ref1 == $ref2` comparisons. (Fixed in session 150.)
- **`$.` is a p-box**: `(defvar |$.|  (make-p-box nil) ...)`. Was plain `0` before session 151 — `box-set` silently no-ops on non-boxes. `local $.` works via `let` dynamic binding. `p-readline` updates via `box-set`.
- **Flip-flop state**: `*pcl-flipflop-states*` — hash table keyed by compile-time integer ID. Each `..`/`...` in source gets a unique ID at code generation time (`$g_flipflop_count` counter in ExprToCL.pm). Not reset between runs (intended: state persists across calls to same function).
- **while condition leading whitespace**: `generate()` in ExprToCL prepends `indent_str x indent_level`. `_process_while_statement` strips this with `$cond_cl =~ s/^\s+//` before regex checks. Other callers of `_parse_expression`/`_parse_condition` may also need this if they do regex checks on results.
- **`(vectorp string)` = T in CL**: Strings are specialized vectors. When checking `(vectorp v)` to detect Perl array refs, always pair with `(not (stringp v))`. Pattern used in `p-map` and `%p-map-copy-scalar`.
- **`p-map` scalar aliasing**: `p-.=` and similar assignment ops return the lvalue box. `p-map` collects lambda return values — if the block ends with `$y .= $x`, the result element IS `$y`. Use `%p-map-copy-scalar` which makes a fresh box for simple scalars to prevent aliasing.
- **`p-defined` vs `%pcl-definedp`**: `p-defined` returns `1`/`""` (Perl values). `%pcl-definedp` returns CL `t`/`nil` (for CL boolean contexts). Use `%pcl-definedp` in `if`/`unless`/`when`/`and`/`or`. `p-//` and `p-//=` use `%pcl-definedp` internally.
- **Array intermediate slots are `nil`**: `p-autoviv-aref-for-hash`, `p-autoviv-aref-for-array`, `p-array-set`, and `(setf p-aref)` all use `(vector-push-extend nil a)` for slots between fill-pointer and target index. `p-delete-array` trim loop removes trailing `nil`s. `p-exists-array` uses `(p-box-p slot)` — so `nil` = not exists, box = exists.

## Key PPI Gotchas
- `%h{keys}` → PPI gives Symbol `%h` + Block `{keys}` (NOT Subscript)
- `%{$ref}{"keys"}` → PPI gives Cast(`%`) + Block(`{$ref}`) + Block(`{"keys"}`), NOT Block + Subscript. Use `$is_kv_hash_deref_block` handler in PExpr.pm. (Compare: `@{$ref}{"keys"}` gives Cast + Block + Subscript — different sigil, different PPI treatment.)
- `-bareword` tokenized as single Word, not operator+word
- PPI's `find` returns `0` (not undef) when nothing found — use `|| []` not `// []`
- `_fix_ppi_glob_after_block`: `<` preceded by Symbol/Number/Quote = always less-than
- **Hex float literals** `0x1.8p-1` misparse as `0x1 . p - 1`. Fixed via `_preprocess_source()` in Parser.pm before PPI sees them. Binary floats `0b1.1p0` NOT yet handled (hexfp.t crash at test 113).
