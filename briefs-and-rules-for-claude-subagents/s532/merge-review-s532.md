## 2. Findings, severity-ordered

**F1 -- BUG, silent wrong, REGRESSION (s529a #3868) -> task #4361.**  A pipe opened inside a `local *FH` scope and not closed explicitly is closed at the scope's end by `%p-local-glob-leave` through `%p-close-impl`, whose pipe arm (`%p-close-maybe-pipe`) waits AND `(box-set $? status)`.  perl's scope-exit close is `io_close(..., not_implicit = FALSE)`: it reaps, it never writes `$?`.
Probe `p-pipe-1.pl`: `{ local(*NIL); open NIL, qq{|$^X -e "exit 23"}; $? = 42; } print $?` -> perl `42`, base `42`, main `5888`.  The explicit close, a file handle and a glob value kept out of the scope all = perl.  Commit: the #3868 member of s529a (MAIN-READY-53 `44d39de3`).  Fix shape: save/restore `$?` around the implicit close in `%p-local-glob-leave` (ONE close path with an `implicit` flag), a guard row in `Pl/t/local-glob-01.t`, io/pipe.t's row out by a one-file run.

**F2 -- BUG, loud raw host error, REGRESSION (s530c #3859) -> task #4362.**  `&CORE::NAME(LIST)` is emitted `(p-amp-spread (p-NAME ...))` because `$user_call` is true for every `&`-call, and `%p-amp-apply` does `(apply 'p-NAME ...)` -- a runtime op spelled as a MACRO cannot be applied.
Probe `p-coreamp-3.pl`: `&CORE::binmode(\*STDOUT)` -> perl `1`, base `1`, main `ERR: pcl:p-binmode is a macro, not a function`; `&CORE::open(my $fh, '<', $0)` perl ok / base ok / main the same error; `&CORE::push(\@a, 3)` main the same error (base: another, pre-existing failure).  Function heads (`&CORE::lc`, `join`, `length`, `sprintf`, `abs`, `die`) are fine on both.  Two facts for the fix: a macro head can never be `apply`ed, and perl's `&CORE::NAME` does NOT ignore the prototype (pp_coreargs enforces the arity: `&CORE::ucfirst(1,2)` dies "Too many arguments") -- so #3859's rule must exclude `CORE::`-qualified names at its ONE predicate (`Pl::PExpr::call_prototype`), with a rule-12 expansion-time die as the belt.  Commit: `b5cbdfe1` (s530c, MAIN-READY-57 `deb1125d`).  The pre-existing `&CORE::keys / pop / wantarray` wrongs seen in the same probe are #1577's family.

**F3 -- LOW, #4081 residue -> task #4363.**  A later import of a name a user module already exported cannot re-win it: `use My::T3; use Test::More tests => 1; ok(1, "a")` -> perl `ok 1 - a` (Exporter re-assigns the glob; a "Prototype mismatch" warning), main `myok(a)` + `# No tests run!`.  Base crashed on the same program, so not a regression.  Mechanism: the runtime-native module's import installs nothing, so the shadowing symbol `%p-own-code-symbol` made keeps the user sub.  Probes `a4081-3.pl` (the divergence) and `a4081-4.pl` (the other order, = perl).

**F4 -- LOW, pre-existing -> task #4364.**  `print "v: ", (require A), "\n";` is a statement drop ("Handle single node of unknown type") on base and main alike; `my $v = require A;` and `eval "require $m"` are right.  Probe `e1688-3.pl`.

**F5 -- pre-existing, re-pointed at #4163.**  `package Foo; sub INC {...}` defines `Foo::INC` in PCL; perl forces INC / ENV / ARGV / STDIN... into `main::` (the reason perlfunc tells hook authors to write `sub Foo::INC`).  Probe `f-forcedmain.pl`: perl `main::INC no-Foo::INC`, base = main `no-main::INC Foo::INC`.  #4163 (pending, filed by s531a) has it.

## For DECIDED

- A scope-exit (implicit) close never writes `$?` -- perl's `io_close(not_implicit = FALSE)`; #3868's `local *FH` close is implicit (#4361).
- `&CORE::NAME(LIST)` is NOT the prototype-ignoring `&` form: perl's pp_coreargs enforces the builtin's arity, and a runtime op spelled as a MACRO can never be `apply`ed -- `p-amp-spread` is for user subs only (#4362).
- A runtime-native module's import is a no-op, so it cannot re-win a name a user module already installed (#4363, the #4081 residue; perl's Exporter re-assigns the glob).
- `"@{name{LIST}}"` / `@{name{LIST}}`: only a `qw()` or quoted list parses in perl; the bare comma list is invalid Perl -- #4140's DECIDED line and guard rows name the shapes perl takes.
- #1687 folds into #1815; comp/filter_exception.t's two rows are rule-9 arity diagnostics (NS), not a hook bug.
- A review probe that merges stderr into stdout, or writes two handles on one fd, judges CONTENT, never interleaving order.
- A probe module must not borrow a core module's name (`B.pm`): PCL's must-win shim answers first and the probe reads the shim.
