## The design -- a SHORT note `$W/scratch/s513i/encode-design.md` before code
- **RUNTIME (generic, two primitives):** `builtin::encode_octets(NAME, STRING, STOP)` -> (octets as a byte-form string, the index of the first UNMAPPABLE character or undef) and `builtin::decode_octets(NAME, OCTETS, STOP)` -> (a string in the UPGRADED form, the index of the first MALFORMED byte or undef); both resolve NAME through `%p-encoding-ef`; SBCL's `sb-ext:string-to-octets` / `octets-to-string` with a handler that REPORTS the position instead of substituting (STOP true = stop there and return the prefix; false = perl's default substitution, U+FFFD on decode and the target encoding's substitution character on encode, and continue).  Strict `UTF-8` (surrogates D800-DFFF and code points above 10FFFF are malformed / unmappable) vs lax `utf8`: a shim-side code-point check in plain Perl if SBCL's utf-8 codec is lax (probe it), else the runtime's.  Decode returns the upgraded form even for pure ASCII (`Encode::is_utf8(decode('UTF-8', "abc"))` is true in perl -- probe), encode returns the byte form.
