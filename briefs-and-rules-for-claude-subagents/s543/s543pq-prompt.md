## Why this batch exists
For months the project counted its own bug list and the list did not shrink: every fix batch probes neighbouring spellings and files each difference.  The USER's rulings of 2026-11-24 changed the question to **"does a program somebody else wrote run right"**, and the Rosetta corpus -- 650 perl-validated programs nobody tuned PCL on -- is the measurement.  A cause that breaks a Rosetta program is ORDINARY by definition (the program is the evidence).  Your product decides the next fix batches: they are ranked by PROGRAMS BROKEN per cause.  So the two things that matter are that **each cause is the real one** (reduced and re-run, never guessed from the diff) and that **the same cause gets ONE task**, whether it was already filed or not.

## The work, per program (lowest name first; keep `scratch/<label>/log.tsv`: name, verdict, cause, minutes, tokens spent roughly)
1. **Re-run** it, perl and PCL; `diff` the outputs.  Note the FIRST differing line and what kind of difference it is (a number's digits, an order, a missing line, a wrong value, a die).
2. **Reduce** it to the smallest program that still differs, perl against PCL -- the program's own text SHRUNK step by step (delete half, re-run, keep the half that still differs), never a guess from the diff.  Stop at about ten lines.  Then REWRITE the reproducer with neutral names and data of your own (it goes into a PUBLISHED task: it must be the language SHAPE, not an excerpt of the program) and re-run that: it must still differ the same way.  **A program can hold TWO causes**: after the first reduction, patch that one spelling in a scratch copy of the program (a perl-equivalent rewrite PCL gets right) and run again -- if it still differs, there is a second cause; record both (the table's cause cell takes `#A + #B`).
3. **Look it up BEFORE filing** -- expect a third or more to be known: `grep` the task store (`~/.claude/tasks/pcl/*.json`: the operator, the builtin, the message text, the shape's keywords; `tools/task-triage.pl` lists the open silent wrongs), `docs/DECIDED.md`, `docs/not-supported.md`.  Run the candidate task's OWN reproducer on your tree: the same mechanism, or only the same symptom?
4. **One task per CAUSE, not per program.**
   - Known and open: APPEND a dated block `=== <label> (Opus 5.5, <date>, CODE <sha>) ===` -- the Rosetta program's NAME (the name only), your neutral reproducer, perl's and PCL's output for it.
