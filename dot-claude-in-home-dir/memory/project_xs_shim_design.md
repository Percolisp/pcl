**Architecture in one line:** recompile CPAN XS from source against replacement headers (`xs/include/pclxs/`) → `libpclxs.so` (pure C: SV structs, arg/mortal stacks, croak=setjmp) → versioned **host vtable** of ~60 C fn pointers (`pclxs_host.h`) → `cl/pcl-xs.lisp` (alien-callables + fixnum handle table; handles not pointers because SBCL GC moves).

**Load-bearing decisions:** D1 source-recompile not binary ABI (cpyext trap); D2 handles not pointers; D3 native-vs-proxy SVs (perf: temporaries never cross the boundary); coercions live host-side (ir-spec §3 is the contract); errors are status codes both directions — NEVER unwind through foreign frames; AV/HV always host-backed in v1.

**Execution:** 5 phases, each with acceptance test; Phase 0 = symbol census (`nm -u` over real-perl-built .so's) BEFORE writing sv.c. Module ladder: hand-written Arith → Digest::MD5 → Time::HiRes → JSON::XS (stretch). Build tool `tools/pcl-xs-build` (Perl; system perl runs xsubpp only). Loader hooks the existing `XSLoader::pl-load` die-fallback.
